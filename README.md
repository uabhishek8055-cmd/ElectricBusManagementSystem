# Electric Bus Management System

## Project Overview

Electric Bus Management System is a Java Swing desktop application integrated with MySQL database. The system is designed to manage electric buses, drivers, routes, trips, and charging stations through a user-friendly graphical interface.

## Technologies Used

* Java
* Java Swing
* MySQL
* JDBC
* Eclipse IDE

## Main Features

* User Login System
* Bus Management
* Driver Management
* Route Management
* Trip Management
* Charging Station Management
* MySQL Database Integration
* Dashboard for managing system information

## Project Structure

* `src` – Java source code
* `bin` – Compiled class files
* `ElectricBusManagementSystem.jar` – Runnable application

## Database

The application uses MySQL as the backend database and connects to it using JDBC.

## How to Run

1. Download `ElectricBusManagementSystem.jar`.
2. Make sure Java is installed on your system.
3. Configure the required MySQL database and credentials.
4. Run the JAR file using Java.

```bash
java -jar ElectricBusManagementSystem.jar
```

## Project Purpose

The purpose of this project is to provide a centralized system for managing electric bus operations, including buses, drivers, routes, trips, and charging stations.
